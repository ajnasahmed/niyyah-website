# Niyyah Group Website Prototype

A responsive Next.js prototype for the Niyyah Group website, designed as a working web experience rather than a static mockup.

## Design direction
- Niyyah = intention
- Warm ivory / black / muted gold palette
- Editorial typography
- Procedural, code-built visual language (no stock photography)
- Intention → Understanding → Creation → Refinement → Impact
- Two current disciplines: Niyyah IT Solutions and Niyyah Marketing
- Responsive mobile layout
- Smooth section navigation and scroll-driven visual progression

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Deploy to Vercel

1. Create a GitHub repository.
2. Upload this project.
3. Import the repo into Vercel.
4. Framework: Next.js (auto-detected).
5. Build command: `npm run build`.
6. Deploy.

## Notes
This is intentionally a prototype. The content, email address, project list, and some interactions are placeholders to be refined before production.
